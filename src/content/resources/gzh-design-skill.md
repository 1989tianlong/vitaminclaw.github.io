## 核心价值

- 一句话：把 Markdown 一键排成可直接粘贴进微信公众号编辑器的精致 HTML
- 根本问题：公众号编辑器排版繁琐、AI 生成内容缺乏专业设计感
- 人话版：写完文章后一键生成漂亮的公众号格式，像给文章穿上精心设计的衣服

## 使用指南

- 第一步（5分钟）：打开 GitHub 页面看效果预览图，确认是否是自己需要的风格
- 第二步（30分钟）：在本地安装 skill：`npx skills add https://github.com/isjiamu/gzh-design-skill`，用示例 Markdown 测试排版
- 第三步（后续）：根据自己内容类型选择主题，定制化调整
- 踩坑预警：公众号对 HTML 有限制（//class/grid/position 等会被过滤），该项目已处理这些兼容性问题
- 与大哥需求的关联：**直接利好公众号内容生产**，可以快速产出高质量排版的文章
- 一句话结论：做公众号内容的神器，省去繁琐排版时间 | 价值评分：⭐⭐⭐⭐
