### 🔹 条目1：Look — 开源跨平台启动器

**日记原文**：`https://github.com/kunkka19xx/look`

**🎯 本质**
- **一句话**：一个本地优先、键盘驱动、不用 Electron 的跨平台启动器，对标 Raycast 和 Alfred，但开源且轻量。
- **根本问题**：Mac/Win/Linux 上缺少一个「既快又小还开源」的应用启动器。Raycast 好但不开源且逐渐臃肿，Spotlight 只在 Mac 上可用，Linux 上的 rofi 又太简陋。
- **人话版**：一个按快捷键就能搜文件、开应用、算数、查剪切板、甚至翻译的小工具，不注册账号、不收集数据、不吃内存。

**📋 基本信息**
- **是什么**：用 Rust 写的原生跨平台启动器（macOS/Windows/Linux），GPLv3 开源
- **核心功能**：
  - 启动应用/打开文件/打开文件夹
  - 内置计算器（`2^10`、`4!`、`sqrt(2)`）
  - 按端口杀进程（`kill :3000`）
  - 每日任务追踪（`:todo`，带 streak 和热力图统计）
  - 剪切板历史搜索（`c"关键词`）
  - 翻译/查词（`t"hello`、`tw"word`）
  - 正则搜索、路径搜索、最近文件浏览
  - 可选 AI 问答功能（macOS 支持 Apple Intelligence 本地模型）
- **目标用户**：开发者、键盘党、效率控、跨平台用户
- **热度/数据**：GitHub 有 Release 下载量跟踪，已发布多个版本。作者自称「用 AI agent 在写这个项目」。

**⚡ 竞品对比**
- **同类**：Spotlight（苹果原生）、Raycast（macOS）、Alfred（macOS）、ulauncher（Linux）、rofi（Linux）
- **差异点**：
  - Look 是**唯一的开源+跨Windows/Linux/Mac+非Electron**启动器
  - 搜索性能极佳（2000 条目 < 1ms）
  - 内置 todo/task 追踪，这是 Raycast/Alfred 需要装插件才有的功能
- **优势**：跨平台、开源、零 Electron（原生程序，占用极小）、无账号无遥测
- **劣势**：生态远不如 Raycast（Raycast 有上千插件）、功能没有 Alfred 丰富（Alfred 有 workflow 引擎）、知名度极低

**🔗 资源**
- 官网：https://noah-code.com/docs/look
- GitHub：https://github.com/kunkka19xx/look
- 文档：仓库内 docs/ 目录
- 演示视频：https://www.youtube.com/watch?v=NBB5bmjnLFU

**🎮 实践指导**
- **第一步（5分钟）**：去 GitHub Release 页下载你对应平台的安装包（Linux 有 AUR、macOS/Windows 有直接安装包），装上试一下 Alt+Space 叫出搜索框
- **第二步（30分钟）**：配置 `~/.look.config`，设置你的常用应用别名（`alias_code`、`alias_term`、`alias_todo` 等），体验搜索文件/剪切板/任务追踪
- **第三步（后续）**：尝试它的 :todo 功能作为轻量任务管理，每天用 `Cmd+K` → `:todo` 管理待办
- **踩坑预警**：项目尚在早期，功能和稳定性比不上 Raycast；跨平台正在推进，某些功能（如最近文件浏览）目前仅 macOS 支持
- **与大哥需求的关联**：如果你日常用键盘多、追求极致效率、或者对 Raycast 不开源/逐渐臃肿有意见，这是个值得关注的替代品。而且项目本身是个不错的开源参考案例
- **一句话结论**：有潜力的 Raycast 开源替代，值得关注但等它迭代几个月更成熟。| 价值评分：⭐⭐⭐

### 🔹 条目2：AGenUI — 高德开源的 UI 生成方案

**日记原文**：`高德开源的AGenUI震撼到了 genui.amap.com`

**🎯 本质**
- **一句话**：高德开源的一套 AI 驱动 UI 生成方案/框架，从 genui.amap.com 访问，应该是用自然语言描述就能生成界面组件或页面。

### 🔹 条目3：Tutti — 人与 AI Agent 协作平台

**日记原文**：`https://github.com/tutti-os/tutti`

**🎯 本质**
- **一句话**：一个让人类开发者和 AI agent 在同一套系统里协同写代码的开发平台/操作系统。
- **根本问题**：当前 AI 编程工具（Copilot、Cursor）只是"辅助补全"，开发者还是主导者。Tutti 的终极目标是**人机平等协作**——Agent 不只是帮你写代码，而是可以独立承担 IDE 级别的工作并和人协同。
- **人话版**：不是一个 IDE 插件，而是一个全新的"操作系统"，人+AI Agent 在里面同时工作，各干各的，互相配合。

**📋 基本信息**
- **是什么**：tutti-os/tutti，一个开源的人机协作开发平台，从 GitHub 结构看是一个 monorepo 项目
- **核心功能**：
  - .codex/skills 目录暗示它有类似 OpenClaw Skills 的 agent 技能系统
  - 包含 apps、packages、services 等多个模块
  - 有完整的 AGENTS.md、CONTEXT.md、CODE_OF_CONDUCT.md 等文档
  - 看起来比较早期但结构完善
- **目标用户**：AI 开发者、尝试人机协作编程模式的团队
- **热度/数据**：GitHub 有 30 issues、62 PRs，有一定活跃度

**⚡ 竞品对比**
- **同类**：OpenClaw、Cline/Claude Code、SWE-agent、Devin（商业）
- **差异点**：
  - Tutti 的名称暗示"大家一起演奏"——强调协作而非替代
  - 有 .codex/skills 体系，类似 OpenClaw 的 Skills 机制
  - 真正在构建一个"OS"层面的东西，而不是 IDE 插件
- **优势**：开源、理念超前、架构设计有想法
- **劣势**：极早期项目、社区极小、可用性未知、可能还在概念验证阶段

**🔗 资源**
- GitHub：https://github.com/tutti-os/tutti
- 文档：仓库内 docs/ 目录
- AGENTS.md：仓库内有相关文档

**🎮 实践指导**
