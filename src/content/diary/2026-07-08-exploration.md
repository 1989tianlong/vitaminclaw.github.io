### 🔹 条目1：gzh-design-skill（公众号排版技能）

**日记原文**：https://github.com/isjiamu/gzh-design-skill

**🎯 本质**
- 一句话：把 Markdown 一键排成可直接粘贴进微信公众号编辑器的精致 HTML
- 根本问题：公众号编辑器排版繁琐、AI 生成内容缺乏专业设计感
- 人话版：写完文章后一键生成漂亮的公众号格式，像给文章穿上精心设计的衣服

**📋 基本信息**
- 是什么：AI Agent 用的公众号排版 Skill（给 Claude Code/Cursor 等 AI 工具用的排版指令）
- 核心功能：6套精选主题、主题生成器、智能章节编号、关键词下划线、代码块/图片/GIF处理、双关卡质量校验
- 目标用户：AI 开发者、内容创作者、公众号运营者
- 热度/数据：GitHub 项目，由甲木 × 摸鱼小李联名共建

**⚡ 竞品对比**
- 同类：壹伴助手、135编辑器、秀米
- 差异点：纯 AI Agent 驱动、Markdown 输入、自动化程度高、代码块处理专业
- 优劣势：✅ AI 原生集成度高、主题可自定义生成 | ❌ 非技术人员上手有门槛、需要理解 Markdown

**🔗 资源**
- 官网：https://github.com/isjiamu/gzh-design-skill
- GitHub：同上
- 文档：README 内置详细使用指南

**🎮 实践指导**
- 第一步（5分钟）：打开 GitHub 页面看效果预览图，确认是否是自己需要的风格
- 第二步（30分钟）：在本地安装 skill：`npx skills add https://github.com/isjiamu/gzh-design-skill`，用示例 Markdown 测试排版
- 第三步（后续）：根据自己内容类型选择主题，定制化调整
- 踩坑预警：公众号对 HTML 有限制（//class/grid/position 等会被过滤），该项目已处理这些兼容性问题
- 与大哥需求的关联：**直接利好公众号内容生产**，可以快速产出高质量排版的文章
- 一句话结论：做公众号内容的神器，省去繁琐排版时间 | 价值评分：⭐⭐⭐⭐

### 🔹 条目2：Kami（文档生成工具）

**日记原文**：https://github.com/tw93/Kami

**🎯 本质**
- 一句话：用一套约束语言生成专业 PDF 文档的设计系统
- 根本问题：AI 能写文档但缺乏统一的设计规范，输出总是"通用灰"和不一致的布局
- 人话版：给 AI 的一套"排版规则说明书"，让 AI 输出的文档像专业设计师做的

**📋 基本信息**
- 是什么：AI 文档设计系统，一套约束语言 + 8个文档模板 + landing page 系统
- 核心功能：简历、One-Pager、Slides、Letter、Changelog、Portfolio 等模板，支持中英日韩
- 目标用户：AI 开发者、内容创作者、产品经理
- 热度/数据：Part of a trilogy: Kaku(写代码) + Waza(训练习惯) + Kami(输出文档)

**⚡ 竞品对比**
- 同类：gzh-design-skill（专注公众号）、Notion AI、ChatPDF
- 差异点：专注 PDF 输出、设计系统化程度高、模板丰富（简历/报告/幻灯片等）
- 优劣势：✅ 输出专业 PDF、设计一致 | ❌ 需要 Claude Code/Codex 环境

**🔗 资源**
- 官网：https://github.com/tw93/Kami
- 安装：Claude Code `plugin install kami@kami` / Codex `codex plugin add kami@kami`
- 示例：包含多个真实 PDF 展示（Musk 简历、Tesla 财报点评等）

**🎮 实践指导**
- 第一步（5分钟）：查看 GitHub 上的 Demo PDF，感受输出质量
- 第二步（30分钟）：安装 Kami 插件，生成一个自己的简历或 One-Pager
- 第三步（后续）：探索更多模板，理解约束语言
- 踩坑预警：大型 CJK 字体需要本地或 CDN 加载，安装时脚本会自动处理
- 与大哥需求的关联：**快速产出专业文档**，适合做报告、产品简介等
- 一句话结论：AI 文档设计领域的设计系统，专业度拉满 | 价值评分：⭐⭐⭐⭐

### 🔹 条目3：OmniRoute（免费 AI 网关）

**日记原文**：https://github.com/diegosouzapw/OmniRoute

**🎯 本质**
- 一句话：一个 API 端点连接 231+ AI 提供商（含 50+ 免费），支持多种 AI 编程工具的智能路由
- 根本问题：AI 工具太多、API 切换麻烦、费用高昂、需要多工具协同
- 人话版：用一个"万能插头"连接所有 AI 服务，省钱又省心

**📋 基本信息**
- 是什么：免费 AI 网关 + 智能路由 + 压缩技术
- 核心功能：连接 Claude Code/Codex/Cursor/Cline/Copilot 到免费 Claude/GPT/Gemini，RTK+Caveman 压缩省 15-95% tokens，智能自动回退，MCP/A2A 协议
- 目标用户：开发者、AI 爱好者、想省钱用 AI 的人
- 热度/数据：177 issues + 50 pull requests，社区活跃

**⚡ 竞品对比**
- 同类：OpenRouter、OneApi、API2D
- 差异点：免费 provider 最多、专注开发者工具集成、token 压缩技术
- 优劣势：✅ 免费 provider 多、省 token 费用 | ❌ 配置有一定复杂度、需要维护自己的网关

**🔗 资源**
- 官网：https://github.com/diegosouzapw/OmniRoute
- 支持：Desktop/PWA 多端支持

**🎮 实践指导**

- 第二步（30分钟）：本地部署测试，连接一个免费 provider
- 第三步（后续）：集成到自己的开发流程，配置自动回退
- 踩坑预警：免费 provider 有速率/额度限制，生产环境需注意稳定性
- 与大哥需求的关联：**省钱方案**，如果大哥有多个 AI 工具可用这个统一管理
- 一句话结论：开发者省钱神器，但配置复杂度较高 | 价值评分：⭐⭐⭐
